1. CRITICAL: FIX CPU CARD FREEZE
==================================================

Currently, when a CPU draws a card, the large card reveal appears but the game can freeze and fail to proceed to the next step.

FIX THIS FIRST.

CPU card flow must always be:

CPU TURN
→ MOVE
→ LAND ON CARD SPACE
→ CARD REVEAL
→ SHOW CARD TO ALL PLAYERS
→ SHOW EFFECT
→ AUTOMATICALLY CLOSE CARD
→ RESOLVE EFFECT
→ CONTINUE GAMEPLAY
→ NEXT TURN / NEXT STEP

Use approximately a 5-second visible card presentation.

The CPU must NEVER require the human player to click a close button.

The timer must actually trigger the continuation of the game state.

Make sure the timer cleanup and game continuation happen reliably even if:
- the card has an effect
- the card targets another player
- an ability also triggers
- the CPU is involved
- multiple events are generated

Do not allow a modal, overlay, timeout, or pending state to leave the match stuck.

Test multiple consecutive CPU card draws.
