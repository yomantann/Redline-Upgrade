REDLINE UPGRADE — PHASE 13
GAMEPLAY CLEANUP, REWARD CLARITY & PLAYER INFORMATION

This phase is primarily a cleanup and usability pass.

Do NOT add major new gameplay systems. Improve the clarity, consistency, visuals, and feedback of the systems that already exist.

Preserve all existing Phase 8–12 mechanics.

==================================================
1. STARTING WEALTH
==================================================

Change starting Wealth so that each player begins with Wealth equal to their assigned career salary.

Example:

Career Salary: $80K
Starting Wealth: $80K

Do NOT start players with a lower/default Wealth value.

Make sure this applies equally to:
- Human players
- CPU players

The salary assigned during career selection should therefore immediately establish the player's starting Wealth.

Update any tests that currently expect the old starting value.

==================================================
2. FINISH-LINE ORDER BONUS
==================================================

Reward players based on the order in which they reach Space 75.

The earlier a player reaches the finish line, the larger their additional Wealth reward.

Create a simple data-driven finish-order reward table that is easy to rebalance.

For example:

1st to finish → largest bonus
2nd → second-largest bonus
3rd → smaller bonus
4th → smallest bonus

Do NOT create another resource.

Add a clear event/UI notification when the player finishes:

"1ST TO FINISH!"
"+$XXK FINISH BONUS"

The bonus should be added to Wealth and included in final game value.

CPU players receive the same rules.

Track actual finish order rather than determining it later from final Wealth.

==================================================

Fix the existing milestone asset visuals so they display clearly everywhere.

4. CARD SPACE VISIBILITY

Whenever ANY player lands on a card space, the card draw/action must be visible to EVERY player in the local game.

Do not make card activity visible only to the player who landed.

Example:

"FROSTBYTE landed on an AI Skill space."

Then show the card being drawn.

The card should be visible to all players.

Show:

- Deck type
- Card image
- Card name
- Card effect
- Who drew it
- Result

This should apply consistently to all six decks:

WEALTH
AI SKILL
FAME
LIFESTYLE
INFLUENCE
GAMBLE

The existing card resolution mechanics should remain unchanged.

8. ABILITY ACTIVATION FEEDBACK

Whenever a character or career ability actually triggers, make it obvious to EVERY player.

Use the existing event system.

Examples:

"GUARDIAN H — CHARACTER ABILITY ACTIVATED"

"AI ENGINEER — CAREER ABILITY ACTIVATED"

Then show the effect:

"+$20K WEALTH"

"+2 AI SKILL"

"PROTECTED FROM PENALTY"

Do not make this a permanent intrusive popup.

Use a short visual notification/event banner and the existing event log.

The player should never wonder why their stats changed.

If an ability is triggered automatically, clearly indicate the trigger.

Example:

"ROLL OF 8 → ABILITY ACTIVATED"

"LANDED ON PLAYER → ABILITY ACTIVATED"

"PURCHASE → ABILITY ACTIVATED"
