REDLINE UPGRADE — PHASE 12

Build the End-Game Titles/Statuses system and redesign the in-game Player Cards for a cleaner, more readable V2 presentation.

Use the existing Phase 8–11 architecture. Preserve all existing gameplay mechanics.

==================================================
1. END-GAME TITLES / STATUS
==================================================

After the endgame result is resolved, evaluate each player's actual game history and final state to assign a fun Redline Upgrade title/status.

Titles should describe HOW the player played, not simply who had the most Wealth.

Use existing game data such as:

- Final Wealth
- AI Skill
- Fame
- Lifestyle
- Influence
- Career
- Career category
- Assets
- Asset levels
- Upgrade Tokens held
- Endgame choice
- Gambling behavior
- Player interactions
- Relevant existing event/achievement data

Do NOT create another scoring system or resource.

Titles should be generated from existing game-state values.

==================================================
2. TITLE EXAMPLES
==================================================

Create a broad data-driven title pool with meme/edgy/futuristic Redline flavor.

Examples:

HIGH WEALTH:

"THE MACHINE"

"THE MENACE"

"THE SURVIVOR"

These are examples only. Expand the pool with similar funny/meme/edgy titles.

Avoid generic rankings such as "Best Player" or "Worst Player."

Titles should be based on measurable game behavior.

==================================================
3. TITLE ASSIGNMENT
==================================================

Each player receives ONE primary final title/status.

The system should evaluate all eligible titles and select the title that best matches the player's actual game behavior using transparent data-driven rules.

Do not create an overall player score.

Do not make titles depend solely on final Wealth.

A player with the highest Wealth should not automatically receive the same title every game.

Store:

endGameTitle
endGameTitleDescription

Example:

THE DEGEN

"Bet everything. Question nothing."

==================================================

==================================================

Include titles based on memorable gameplay events where the existing event system supports them.

Examples:

- Heavy gambling
- Multiple Double Downs

- High Fame
- High AI Skill
- High Influence
- High Lifestyle
- Strong asset collection
- Multiple asset upgrades

Use actual event/game history where available.

Do not invent events that the current game does not track.

If an exact behavior is not currently tracked, identify it rather than creating an unrelated new system.
