3. CAREER TERMINOLOGY CLEANUP
==================================================

Remove unnecessary player-facing career classifications that are not part of the actual six-deck system.

Do NOT introduce "Professional" as a separate player-facing category simply because a career such as Doctor is professional.

Do NOT introduce "Media/Fame" as a separate career classification.

The existing Career Deck system should be the primary connection.

Use:

CAREER

CAREER DECKS

[DECK 1] [DECK 2]

For example, a Doctor should simply display the actual deck affinities assigned to Doctor.

An Influencer should display its actual deck affinities, including FAME where appropriate.

Do not create another terminology layer that players have to learn.

The underlying career category/tag system can remain if required by gameplay code, but unnecessary internal categories should not clutter the player-facing UI.

==================================================
4. REMOVE THE COMPLEX NUMBER-CHANGE UI
==================================================

Remove the previously planned/implemented requirement to show every numerical change as:

$120K → $155K
+$35K

Do NOT build or maintain a complicated before/after number-change system.

The game should simply communicate the result.

Examples:

+ $35K WEALTH

+2 FAME

+2 AI SKILL

Keep result notifications clear and readable.

Do not show unnecessary before/after calculations.

Do not create additional state-tracking solely for this UI.

==================================================
5. CPU CARD REVEAL MUST CONTINUE AUTOMATICALLY
==================================================

When a CPU draws a card:

The card should still appear prominently for all players.

However, it must NOT remain on screen indefinitely.

Create an automatic card-reveal timer.

Target:

5 seconds

Sequence:

CPU DRAWS CARD
→ LARGE CARD REVEAL
→ CARD EFFECT VISIBLE
→ approximately 5 seconds
→ CARD CLOSES
→ EFFECT RESOLVES/CONTINUES
→ GAMEPLAY RESUMES

The timer should be visible subtly if useful, but do not make it distracting.

The player should have enough time to read:

- Deck
- Card name
- Artwork
- Effect
- CPU player who drew it

Do not require a player to manually close the card for CPU turns.

Human card interactions can remain interactive where appropriate.

The important requirement is:

CPU card reveals must NEVER block gameplay indefinitely.
