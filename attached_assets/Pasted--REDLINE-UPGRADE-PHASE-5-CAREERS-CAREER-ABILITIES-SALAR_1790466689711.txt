# REDLINE UPGRADE — PHASE 5

## CAREERS + CAREER ABILITIES + SALARY + WEALTH ECONOMY

Phase 4 is complete.

We now have:

* 75-space board
* 1 human + 3 CPU players
* 3D character pieces
* 2d4 dice
* Dice roll animation
* Turn system
* Movement system
* Landing-space UI

Now add the player's **career, salary, and initial Wealth system**.

Keep this phase focused and data-driven.

---

# 1. CAREER SELECTION

At the beginning of the game, after character selection, every player receives a random career.

The human sees a short Career Assignment screen.

The 3 CPU players automatically receive random careers.

Initially, do not allow duplicate careers.

Each career should contain:

* Career ID
* Career name
* Description
* Career icon
* Career ability
* Four salary tiers
* Salary values
* Starting Wealth modifier
* Starting stat modifiers

# 5. WEALTH

Do NOT create a separate money/cash resource.

The player's financial resource is:

**WEALTH**

Starting Wealth should be determined by:

**Salary + starting modifier**

Use a configurable formula so the economy can easily be rebalanced.

---

# 6. HOW PLAYERS ACQUIRE WEALTH

Wealth should NOT simply increase automatically every turn.

Players should primarily acquire Wealth through the board.

Build the system to support:

### Starting Wealth

Based on career/salary.

### Passing Spaces

Certain board spaces can award Wealth when a player passes them.

Example:

**PAYDAY**

`+ $25K`

The player receives the Wealth when crossing the space, not necessarily when landing on it.

### Landing Events

Some spaces can add or subtract Wealth.

### Career Events

Some spaces can affect players based on their career.

Example:

**AI BOOM**

`All AI Engineers gain +$30K`

This should affect ANY player currently holding the AI Engineer career.

### Targeted Career Events

Some spaces can affect one or more players with a particular career.

Example:

**LAW FIRM SCANDAL**

`All Lawyers lose $20K`

### Positive Career Events

Example:

**TECH IPO**

`AI Engineers and Startup Founders gain $40K`

The game engine should support multiple career targets.

# 9. PASSING SPACE LOGIC

The movement system must distinguish between:

**PASSING a space**

and

**LANDING on a space**

Example:

Player moves:

12 → 13 → 14 → 15 → 16

If space 15 is a PAYDAY space:

The player receives its Wealth reward when moving through space 15.

If the player lands on 16, then space 16's landing effect is processed.

This distinction will become important later.

---

# 10. CAREER-TRIGGERED EVENTS

Create the foundation for spaces that affect careers.

Example:

**AI FUNDING BOOM**

Career icon: AI Engineer

Effect:

`AI Engineers gain +$50K`

The system should search the active players and apply the effect to every player whose career matches.

Another example:

**TRUCKING STRIKE**

Career icon: Gig Worker

Effect:

`Gig Workers lose $20K`

These events can eventually be used for:

* Wealth
* AI Skill
* Fame
* Lifestyle
* Influence
* upgrades
* other effects

For now, implement the basic Wealth version.

# SUCCESS CRITERIA

I should be able to:

1. Select my character.
2. Receive a random career.
3. Receive one of four salary tiers.
4. Receive starting Wealth.
5. See my career icon and ability.
6. See the same information for the CPU players.
7. Play the existing 75-space board.
8. Pass through a Wealth-awarding space and receive Wealth.
9. Land on a Wealth event and gain/lose Wealth.
10. Trigger a career-based event.
11. Have the event automatically affect every player with the matching career.
12. See Wealth changes visually.
13. Continue playing normally with the existing 2d4 system.

The foundation should support future spaces where **any player can trigger an event that affects another player or every player with a specific career.**

Keep the system data-driven and easy to expand.

**STOP after this phase.**
