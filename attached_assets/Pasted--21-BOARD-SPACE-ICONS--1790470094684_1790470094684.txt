22. BOARD SPACE VISIBILITY
==================================================

Special spaces should visually stand out from normal spaces.

Use:

- Large centered icon
- Strong silhouette
- Slight 3D elevation
- Subtle glow or border
- Consistent icon placement
- Short optional label

The icon should remain readable when the board is zoomed out.

When the player zooms in, the icon and label should become more detailed.

Do not make every space overly flashy.

Normal spaces should remain visually quieter so special spaces naturally stand out.

26. BOARD SPACE DATA
==================================================

Make sure every board space has a clear data type.

Example:

{
  id: 35,
  type: "CAREER_CHANGE",
  icon: "career_change",
  label: "Career Change",
  trigger: "LAND_OR_PASS"
}

Use the same data to determine:

- Icon
- Visual styling
- Tooltip
- Trigger behavior
- Milestone behavior

Do not hardcode the visual separately from the board-space data.
