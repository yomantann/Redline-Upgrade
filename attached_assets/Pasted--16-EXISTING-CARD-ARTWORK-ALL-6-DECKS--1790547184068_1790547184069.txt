==================================================
17. CARD ART DIRECTION
==================================================

Each deck should have a recognizable visual identity while still feeling like part of the same Redline Upgrade universe.

Cards should feel like premium futuristic board-game cards.

Overall style:

- dark futuristic
- edgy
- AI/technology influenced
- slightly chaotic
- meme-friendly where appropriate
- premium tabletop game
- strong visual silhouettes
- readable at card size

The six decks should NOT all look identical.

Each deck should have its own visual language.

WEALTH:
Money, luxury, markets, deals, assets, financial chaos.

AI SKILL:
AI, robots, neural networks, coding, automation, futuristic technology.

FAME:
Spotlights, media, influencers, viral moments, celebrity culture.

LIFESTYLE:
Luxury, health, experiences, status, leisure, ridiculous lifestyle choices.

INFLUENCE:
Power, networking, politics/corporate influence, social control, reputation.

GAMBLE:
Risk, dice, casino energy, speculation, jackpots, catastrophic losses.

==================================================
18. CARD DESIGN
==================================================

Keep the existing card UI structure.

Artwork should work as the main visual area of the card.

The existing card should still clearly display:

- Card name
- Deck
- Description/effect
- Any existing value
- Existing buttons/actions

Do not bury important card text inside generated artwork.

Do not generate artwork containing the card's gameplay text.

The UI should render the text separately.

==================================================
19. INDIVIDUAL CARD ART
==================================================

Every existing card should have its own distinct artwork.

Avoid producing:

"same image with a different color."

The artwork should reflect the actual card's NAME and EFFECT.

For example, if an existing card involves:

- market crash → visually communicate a market collapse
- viral fame → visually communicate going viral
- AI breakthrough → visually communicate a major AI event
- luxury purchase → visually communicate wealth/status
- gambling win → visually communicate a high-risk jackpot

Use the existing card definition to determine the appropriate visual concept.

Do not change the card's meaning.

==================================================
20. MEME / EDGY CONTENT
==================================================

Where the existing card name/effect is humorous, edgy, absurd, or meme-oriented, let the artwork reflect that personality.

However:

Do not add new gameplay text.

Do not add offensive or unrelated imagery simply for shock value.

The artwork should support the existing card concept.

==================================================

Artwork should not overpower the gameplay information.

The artwork should enhance the card rather than make it harder to read.
