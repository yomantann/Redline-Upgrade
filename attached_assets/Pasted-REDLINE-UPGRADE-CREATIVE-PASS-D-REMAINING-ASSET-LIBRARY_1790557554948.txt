REDLINE UPGRADE — CREATIVE PASS D
REMAINING ASSET LIBRARY

This is a CREATIVE/ASSET-ONLY pass.

Do NOT change gameplay rules, event logic, card effects, character abilities, careers, movement, board layout, or game state.

The goal is to complete the remaining visual asset library for Redline Upgrade so future GitHub implementation can use polished assets without needing another large image-generation pass.

==================================================
1. AUDIT EXISTING ASSETS FIRST
==================================================

Before creating anything, inspect the current project and identify:

- existing character artwork
- existing 21 character game-piece artwork
- existing 90 card artwork
- existing six deck artwork
- existing milestone artwork
- career artwork
- board artwork
- space icons
- Gamble artwork
- endgame artwork/components
- any existing UI/background assets

DO NOT recreate assets that already exist and are working.

Reuse the existing visual language.
