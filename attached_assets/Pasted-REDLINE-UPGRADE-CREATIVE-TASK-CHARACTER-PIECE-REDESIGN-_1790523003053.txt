REDLINE UPGRADE — CREATIVE TASK
CHARACTER PIECE REDESIGN / QUALITY PASS

IMPORTANT:
This is a VISUAL DESIGN task only.

Do NOT modify:
- Game logic
- Player state
- Character IDs
- Character selection
- Board movement
- Dice
- Careers
- Cards
- Events
- Multiplayer
- Game rules

==================================================
GOAL
==================================================

Review all 21 existing Redline Upgrade character game pieces.

Some current pieces look acceptable, but others look like generic 3D humanoid figures with the character's colors/images applied to them.

That is NOT the desired final style.

The goal is:

"Collectible board-game pawn meets stylized character figurine meets Redline meme character."

Each piece should have a DISTINCTIVE SILHOUETTE that communicates the character even without the original portrait beside it.

Do NOT simply convert the character portrait into a 3D human.

Do NOT create generic humanoid bodies for every character.

==================================================
DESIGN PRINCIPLE
==================================================

Each character piece should be designed around:

1. Character personality
2. Character visual identity
3. Character meme/concept
4. Existing character artwork
5. A distinctive silhouette

The piece should still be recognizable when:

- Very small on the board
- Viewed from above
- Viewed from the side
- Shown as a black silhouette

If the piece could belong to a completely different character, redesign it.

==================================================
IMPORTANT EXAMPLE
==================================================

The current piece shown for the cat character is NOT good enough.

It currently looks like:

- Generic humanoid body
- Generic head
- Random wings/arms
- Character colors applied afterward

Instead, the character concept should drive the physical design.

For a character represented by a screaming/glitching cat image, the piece could use:

- Oversized cat head
- Distinctive ears
- Aggressive/open-mouth expression
- Cat-like body proportions
- Tail or other recognizable cat silhouette
- Glitch/electronic details
- Character-specific base

It should look like a stylized collectible cat character, NOT a human wearing cat colors.

This principle applies to every character.

==================================================
STYLE
==================================================

The overall collection should feel unified.

Think:

- Premium board game
- Collectible miniatures
- Futuristic
- Dark
- Slightly ridiculous
- Meme-driven
- Cyberpunk
- Redline aesthetic

Avoid:

- Generic toy soldier
- Generic chess pawn
- Generic humanoid
- Realistic human anatomy
- Overly complicated miniature detail
- Random accessories that don't relate to the character

==================================================
3D DESIGN REQUIREMENTS
==================================================

Each piece should have:

- Distinctive silhouette
- Stable base
- Character-specific upper body/head
- 2–4 recognizable design features
- Appropriate material treatment
- Subtle Redline-style detailing

The base can remain consistent across characters so they clearly belong to the same game.

The CHARACTER portion should be different.

Think:

COMMON BASE
+
UNIQUE CHARACTER FIGURE

rather than:

COMMON HUMAN FIGURE
+
DIFFERENT TEXTURE

==================================================
IMPORTANT: PRESERVE EXISTING ART
==================================================

Do not remove or replace the original character artwork from the character selection system.

The 3D piece is a separate representation of the character.

The goal is for the portrait and 3D piece to clearly feel like the SAME character.

==================================================
QUALITY STANDARD
==================================================

Before accepting a piece, ask:

1. Can I identify the character from the silhouette?
2. Does the shape reflect the character's concept?
3. Does it look like a designed collectible miniature?
4. Does it avoid looking like a generic human?
5. Does it remain readable when small on the board?
6. Does it look good beside the other 20 pieces?

If the answer is no, redesign it.

==================================================
DO NOT REDESIGN EVERYTHING AUTOMATICALLY
==================================================

Review all 21 pieces first.

Keep pieces that already meet this standard.

Spend the redesign effort on the weakest pieces.

Prioritize silhouette and character identity over adding more detail.

==================================================
BOARD COMPATIBILITY
==================================================

All pieces must continue to:

- Fit on existing board spaces
- Maintain existing player positioning
- Render efficiently
- Work with existing camera/zoom
- Work with CPU players
- Work with player selection
- Use the existing character IDs

Do not change gameplay code.

==================================================
FINAL RESULT
==================================================

The collection should look like 21 unique collectible game pieces.

Someone should be able to see the pieces without the character portraits and say:

"Those are 21 different characters."

Not:

"Those are 21 versions of the same person."

STOP after completing this visual character-piece pass.
