---
name: Cosmetic catalog identifiers
description: Preserve ownership when cosmetic filenames or display names change.
---

Keep a cosmetic's catalog ID stable when renaming its source asset or display label. Ownership and equipped records refer to the catalog ID, so changing a filename-derived ID can make an existing unlock appear lost.

**Why:** item labels and artwork can change without changing what a player owns.

**How to apply:** maintain an explicit ID mapping for renamed files and update the catalog name and asset path in place. Only assign a new ID when the product is intentionally a different cosmetic and ownership migration has been considered.
