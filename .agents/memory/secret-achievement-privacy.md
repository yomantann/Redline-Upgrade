---
name: Secret achievement privacy
description: Privacy and measurable-rule decisions for hidden lifetime achievements
---

Keep secret names, descriptions, requirements, rarity, artwork, and numeric progress on the server until the account unlocks that achievement. Locked API rows may identify generic mystery slots and unlock state only; omit progress, reward, and all revealing metadata. Filter secret metrics from public profile summaries.

Use a frozen, explicitly versioned asset ID list for collection-completion objectives so later catalog additions do not invalidate earned achievements. The current game has four equipment slots, so "five distinct held assets" is impossible; use all four distinct slots for the perfect-collection feat. There is no sale action, so loss-free objectives currently treat transfers away as losses. The game's defined tracked dimensions for the six-dimension objectives are Wealth, four player attributes, and asset portfolio value. Only milestones the player actually lands on are eligible for the perfect-milestone feat.

**Why:** The achievement brief requires hidden criteria and exceptional but measurable goals without changing game mechanics; several literal thresholds do not match the current rules.

**How to apply:** Keep evaluators server-authoritative, expose a shared mystery placeholder until unlock, and revise any rule only alongside a versioned, tested definition based on the actual game mechanics.
