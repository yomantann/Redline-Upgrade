---
name: Player stat feedback
description: Product constraints for showing temporary Wealth and attribute changes during a match.
---

Keep transient feedback attached to the exact changed stat on the affected player's card. The permanent current value remains visible after the signed delta and source pulse disappears. Do not add a separate effects section, panel, or event log, and do not change gameplay mechanics.

**Why:** the user explicitly scoped stat-change feedback to the affected value and rejected shared or persistent effects UI.

**How to apply:** Keep future changes to this feedback within the stat cells on player cards; preserve the current value and gameplay rules.
